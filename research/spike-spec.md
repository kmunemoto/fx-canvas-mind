# 1時間足の急騰・急落（#395）

## 指示
- 2026-11-05、オーナーの言葉: 「チャートが1時間足で急激に上がったり、下がったりしたらメールください。」
- 聞き返して決めたこと（オーナーの選び）:
  - 急激の大きさ: 「3倍以上」。ふだんの1時間の値幅の3倍。
  - 送る時: 「足の途中ですぐ」。
  - 銘柄: 「5ペア＋金」。
  - チャート: 「チャートにも出す」。

## 決まり
- **足**: 1時間足。
  - 5ペア（USD/JPY・EUR/JPY・AUD/JPY・EUR/USD・AUD/USD）は、GMO の買値と売値の中間です。チャートと同じやり方で丸めます。
    - 買値と売値を数（浮動小数）にして足し、2で割り、チャートの桁（円のペアは3桁、ほかは5桁）に `toFixed` で丸めます。
    - 中間値の多く（このデータでは約85%）は、ちょうど半分の単位で終わります。それがどちらに丸まるかは、浮動小数の計算で決まります。丸め方を変えると、印の付く足が変わることがあります（下の「測ったこと」）。
  - 金は「金」の項のとおりです。
- **ふだんの1時間の値幅 R**: その足より前の確定足120本の「高値 − 安値」の平均です。
  - 本数で数えます。週末・休場・データの欠けで時間が空いていても、その前の足を数えます（メールでは、下の「遅れ」の決まりがあります）。
  - 古い足から順に足し、120 で割ります。
  - 120本に足りない時、または R が0より大きい有限の数でない時は、判定しません。
- **急騰**: その足の高値 − 始値 ≥ 3 × R。
- **急落**: その足の始値 − 安値 ≥ 3 × R。
  - 1本の足が両方になることもあります（上にも下にも大きく動いた足）。その時は両方です。
  - 比べるのは浮動小数（JavaScript の数）のままです。10進でちょうど 3R の足が、浮動小数の誤差で届かないことがあります（作り物のデータでは起きました。実データでは起きていません）。
  - 高値が始値より下などの壊れた足も、そのまま計算します（動いた幅が負になり、届きません）。データにはありませんでした。
- **倍数**: 急騰は（高値 − 始値）÷ R、急落は（始値 − 安値）÷ R です。メールとチャートには、小数1桁（`toFixed(1)`）で出します。
- **足の途中**: 作られている途中の足も、その時までの高値・安値で同じように見ます。
  - 確定までに値段が戻っても、一度届いたら急騰（急落）です。
  - チャートの確定足の印も、その足の高値・安値で見るので、同じ足に付きます。

## メール（APP: アプリで決めたこと）
- **見る時**: 巡回（毎分）のたびに、購読のある銘柄の、作られている途中の1時間足を読んで見ます。
  - 確定から10分以内の一番新しい確定足も見ます。確定の直前に届いた動きを、確定の後の巡回で拾うためです。
- **送る数**: 1本の足、1つの向きにつき1通です。記録の重なりを防ぐ鍵（足の始まり・向き・ルール）で数えます。
- **R の保存**: 1時間足ごとの R は、その時間に1度だけ計算し、表 `spike_ranges` に残します。毎分の巡回は、その小さな行だけを読みます。
  - 理由: R の元の足は、金の保存足が1回約120KB、ペアの GMO のファイルが約150KB あり、毎分読むとデータベースの通信量（無料の枠は月5GB）を超えるためです。
  - 作り直す時: 前に作った R が、1本遅れた足から作られていた時、または作れなかった時です。金は新しい保存足が読まれた時、ペアはその分の巡回が1時間足を読んだ時に作り直します。
  - 3日より古い行は消します。
- **遅れ**: 見る足の前の確定足が、市場の開いていた時間で2本以上欠けている時は、判定しません（`stale`）。週末と、金の毎日の1時間（ニューヨークの17時台）は、欠けとは数えません。
  - 1本までは判定します（金の保存足は、正時の1分後に読まれるため）。その時は、メールに「保存した足が1本遅れていた」と書きます。
- **送り方**: 送る前に、その足・その向きの行が `signal_alerts` にもうある人を外します。そのうえで、記録の重なりを防ぐ鍵で1通にします。
  - 1つの分で送れなかった人（読み込みの失敗など）は、次の分の巡回で送ります。
- **見ない時間**: 市場が閉まっていた可能性のある時間（金曜21時 UTC から日曜22時 UTC まで）は、巡回そのものが止まります（前からの決まり）。
  - 夏時間では、週の最後の足（金曜20時 UTC に始まる足）の確定のあとの10分を見ません。
  - 冬時間では、GMO の週の最後の足が金曜21時 UTC に始まるなら、その足は途中も見ません。冬の金曜の終わりは、まだデータで確かめていません。
- **向きの記録**: `signal_alerts.side` に、急騰は BUY、急落は SELL として残します。表の制約に合わせるためで、売買の合図ではありません。メールの文には「急騰」「急落」とだけ書きます。
- **時刻の記録**: `signal_alerts.closed_at` には、足の確定ではなく、動きを見た時刻（巡回の時計）を入れます。送るまでの秒数を、見てから送るまでで数えるためです。
- **入口の記録**: `entry` は、見た時の値段です（作られている途中の足ならその終値、確定足ならその終値）。損切りと利確は無しです。
- **記録の ID**: `spike_1h_x3_r120_v1`。

## 金
- **R**: Twelve Data の1時間足（アプリが保存している足。MACD のメールと同じ）の確定足から作ります。
  - 見る足より前の120本を使います。保存足が1本遅れている時は、その分古い120本になります。
- **作られている途中の足**: Swissquote の値段を毎分記録した1分足（`gold_tick_bars`）から作ります。
  - その時間（UTC の正時から）の分を集めます。始値はその時間の最初の分の始値、高値・安値はその時間の分の中の最高・最安です。
  - その時間の最初の分が、正時から2分を過ぎて始まっている時は、始値が分からないので判定しません。
- **確定から10分以内の一番新しい足**: 同じく1分足から作ります。
- **毎日の最初の1時間**: 金の取引の再開（夏は 22:00 UTC、冬は 23:00 UTC。日本時間の朝7時台・8時台）の1時間は、判定しません。
  - 毎分の記録が、再開から約5分後に始まるためです。2026-10-28〜11-04 の再開6回とも、最初の分は :05 でした。
  - 過去の Twelve Data の足（2026-09-14〜11-05）では、この時間の足38本に、3倍の急騰・急落は0本でした（一番大きくて2.07倍）。
- **R と途中の足の出所が違います**（Twelve Data と Swissquote）。チャートの金の足は Twelve Data の足で、作られている途中の足は、画面が最初に受け取った値段から始まります。そのため、チャートの金の印とメールは食い違うことがあります。

## チャート
- 一覧の「急騰・急落（1時間足）」。最初からオンです。
- 移動平均線のチャートには出しません（ほかのメールの印と同じです）。
- インジケーターを使えないプランでは 🔒 で出ません。
- 1時間足のチャートだけに出します。ほかの時間足では、一覧に「1時間足のチャートで出ます」と書きます。
- 急騰の足は高値の上に ▲「急騰 3.4倍」、急落の足は安値の下に ▼「急落 3.4倍」。
  - 作られている途中の足は「（途中）」を付けます。
  - 触れると、始値・高値（安値）・動いた幅・R・倍数を出します。
- 画面の足で数えます。リアルタイムチャートが持つ足（確定足と作られている途中の足）と、その前の履歴の足を使い、それより前の足が120本ない所には付けません。
  - リアルタイムチャートは、急騰・急落がオンの1時間足では、履歴の足を読みます（チャート自身の足は、確定足120本と途中の足1本だけなので）。
- 触れた時の動いた幅と R は、メールと同じ単位（pips。金はドル）で出します。
- 印の文字が足や三角に重ならないよう、印のある時は、チャートの上下の余白を広くします。

## 測ったこと・測っていないこと
- 過去の回数（データベースの1時間足、2026-07-19 23:00〜2026-11-04 20:00 UTC に始まる足、約15.4週、5ペア）:
  - チャートと同じ丸めで、急騰36回・急落116回、合わせて152回（週に約9.9回）。
    - 丸めない中間値では急騰35回・急落116回でした。違いは USD/JPY 2026-07-23 13:00 UTC の1本で、チャートの丸めの時だけ 3.0003倍です。
  - 1本で両方だった足は1本（EUR/USD）。
  - 倍数ごと（同じ足、チャートの丸め、5ペア合計）: 3倍 152回、3.5倍 107回、4倍 78回、5倍 41回。
  - 仕様だけから別に書いた Python で、同じ足（9,880本）を数え直し、全ての足の判定が TS と一致しました（作り物 96,000本でも一致）。
- 金（アプリが保存している Twelve Data の1時間足、2026-09-14 13:00〜2026-11-05 01:00 UTC に始まる足、約7.4週）: 急騰2回・急落6回。
  - これはチャートと同じ Twelve Data の足の高値・安値で数えたものです。メールの金の途中の足（Swissquote の毎分の足）で数えたものではありません。
- 急騰・急落のあと値段がどう動いたか（その後も続くか、戻るか、勝率）は測っていません。
